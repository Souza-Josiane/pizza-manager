# 🍕 Pizza Page

**PizzaPage** is a CRUD web application developed as part of the *Intro to Web Programming using PHP* course. The main goal was to create a visually polished system focused on managing pizza orders, with user registration and login functionality.

## 📋 Description

This project allows the user to:

- Create an account by registering a profile.
- Log in to view and place pizza orders.
- Create, view, edit, and delete pizza orders.
- Upload images related to your profile.
- Navigate through pages with a consistent header and footer layout.

## ✅ Features

- **User Registration and Login**: Users must create a profile to place orders and view their order history.
- **CRUD functionality** for pizza orders.
- **Image upload** when creating a profile.
- **Order history page** with options to update and delete orders.
- **Responsive layout** styled with CSS (Bootstrap optionally used).

## 🛠️ Technologies Used

- **PHP** (backend and CRUD logic)
- **MySQL** (order and user data storage)
- **HTML/CSS** (structure and styling)
- **JavaScript** (basic interactivity)
- **Bootstrap** (optional styling support)
